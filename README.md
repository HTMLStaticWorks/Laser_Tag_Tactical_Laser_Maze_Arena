# Laser Tag & Tactical Laser Maze Arena

A premium, highly immersive website for a futuristic Laser Tag and Tactical Laser Maze Arena. Designed with a cyberpunk aesthetic, featuring neon glow effects, glassmorphism, and responsive layouts.

## Features

- **Futuristic UI/UX**: Cyberpunk design language with vibrant neon colors and smooth transitions.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop viewports (320px to 1920px+).
- **Interactive Pages**:
  - **Arena**: Explore the tactical layout and 3D maps.
  - **Booking**: Cyberpunk-themed booking system.
  - **Leagues**: Information about eSports leagues and tactical tournaments.
  - **Parties**: Packages for birthday parties and corporate events.
  - **Waiver**: Online digital waiver system.
- **Authentication**: Custom login and registration pages with social auth UI.
- **Animations**: GSAP and CSS-based micro-animations for an interactive feel.

## Tech Stack

- **Frontend**: HTML5, Vanilla CSS3, JavaScript (ES6+)
- **Design System**: Custom CSS variables for global theming (Neon Pink, Cyber Blue, Matrix Green).
- **Icons**: Font Awesome / Lucide (integrated via CDN/SVG).

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/HTMLStaticWorks/Laser_Tag_Tactical_Laser_Maze_Arena.git
   ```
2. Open `index.html` in your browser.

## Project Structure

- `index.html`: Landing page.
- `arena.html`: Arena details and map.
- `book.html`: Booking interface.
- `league.html`: League and tournament info.
- `party.html`: Event packages.
- `login.html` / `register.html`: Auth pages.
- `waiver.html`: Digital waiver.
- `index.css`: Global design system and component styles.
- `script.js`: Interactive logic and animations.
- `assets/`: Optimized images and graphical assets.
